# 机密变量

CurlGo 将当前工作区的机密值按环境分开保存。请求只写 `{{secret.token}}` 等引用，发送时才从当前环境注入实际值。普通变量仍使用 `{{base_url}}`。

## 桌面端操作

在左下角打开「机密变量」，选择环境并点击「解锁」。首次解锁会在 macOS 登录钥匙串中创建随机主密钥，同时初始化加密文件；后续解锁读取同一密钥。系统可能显示钥匙串访问提示。

填写名称 `token` 和机密值，点击「保存机密变量」。名称不含 `secret.` 前缀；保存会新增或覆盖当前环境的同名值。列表只显示引用和遮罩。点击「编辑」后，编辑框默认隐藏值；「显示编辑值」只影响当前编辑框。保存、取消编辑、切换环境、离开页面和锁定都会清空编辑框。

编辑框只接受单行粘贴，含换行的粘贴会被拒绝并保留原值，避免系统将换行改为空格。响应提取和 CLI 文件中的机密值仍支持换行，可用于请求正文。清空或切换编辑对象时同时重建输入控件，撤销操作不会恢复上一次编辑的机密。

在请求的 Bearer Token 中填写 `{{secret.token}}`，或在 Basic 密码、API Key、URL、请求头、原始正文、multipart 文本项中使用同样的引用。发送时冻结当前请求和环境，历史、收藏及草稿保留引用。

点击「锁定」或关闭应用会释放缓存的主密钥和机密映射。重启后默认锁定，锁定时变量名称也不可见。含机密引用的请求会在网络连接和历史记录之前失败；不含机密引用的请求仍可发送。已发送请求使用发送时的值，锁定不会撤回已经发出的数据。Go 的字符串和请求副本可能仍存在于内存中，因此不保证所有副本即时清零。

## 环境与引用规则

`secret.` 是保留命名空间。普通环境中的 `secret.token` 不会替代机密值，普通设置也不能保存该前缀的键。缺失机密、未解锁或选错环境均会阻止请求；不会回退到另一个环境、系统环境变量或普通变量。

机密名称使用 `[A-Za-z_][A-Za-z0-9_.-]*`，最多 256 字节，且不能再以 `secret.` 开头。值是有效 UTF-8 字符串，最多 64 KiB，允许为空。换行可用于正文，仍会被 HTTP 请求头和鉴权字段的校验拒绝。替换只执行一次，替换值中的 `{{…}}` 保留为字面量。

每个桌面机密文件跨环境最多 1000 个变量，明文 JSON 总量最多 1 MiB。环境名称非空、最多 1024 字节，不接受控制字符。不存在自动过期或服务器令牌吊销机制；需要轮换时覆盖同名值，并在服务端撤销旧凭证。

普通 `token` 变量和此前直接填写在鉴权、URL 或正文中的凭证继续按原方式保存，不自动迁移、识别或删除。需要加密的凭证应由用户添加到「机密变量」，将请求改为引用，并自行检查旧的明文文件及备份。

## 存储与恢复

macOS 使用现有工作区目录 `~/Library/Application Support/QingzhouAPI/`：

| 位置 | 内容 |
|---|---|
| 登录钥匙串，服务名 `com.echovic.curlgo.vault.<文件 ID>` | 随机 32 字节 AES 主密钥，账户名 `master-key` |
| `secret-vault.json` | 版本、随机文件 ID、随机 nonce、AES-256-GCM 密文；名称、环境和机密值都在密文中 |
| `workspace.json` 及 `.bak` | 普通配置、请求引用、历史与 Cookie；不包含注入的机密值或主密钥 |

目录权限为 0700，加密文件为 0600。每次修改使用新的随机 nonce，验证整个候选映射后加密、同步临时文件并原子替换，最后更新内存。写入失败保留先前内存值；没有自动明文备份。版本、文件 ID 和固定用途参与认证，元数据或密文被修改会导致解锁失败。

钥匙串只在显式解锁或首次初始化时访问，不通过命令行参数传递密钥。删除最后一个变量不会删除主密钥。现有加密文件对应的钥匙串项缺失、访问被拒绝或密文损坏时，应用不会生成新密钥覆盖原数据。恢复需要原加密文件和与其 ID 对应的原钥匙串项；单独复制文件不能恢复机密。无法恢复密钥时无法解密，应保留原数据并重新配置凭证。

桌面加密存储目前支持 macOS。其他平台仍可使用普通环境和 CLI 的显式机密文件。

## 复制 curl 与集合

「复制 curl」替换普通变量，始终保留机密引用，不读取或解锁机密文件。Basic 含机密引用时使用 `--user 'username:{{secret.password}}'`，不会将引用编码为固定 Basic 请求头。接收方须配置机密后才能通过 CurlGo 发送。

API Key 的名称若来自机密引用，发送仍可使用，但复制 curl 会提示需要公开名称：标准 curl 文本无法保留未知名称对同名 Header / Query 的覆盖规则。机密导出若包含普通替换值引入的字面 `{{…}}`，也会明确拒绝，避免导入后重复展开并改变请求。

Query 鉴权要求复制时 URL 的查询前缀和参数名称不含机密引用，以保留已有 Query 的拼接与同名覆盖规则；参数值仍可使用机密引用。同时存在请求 Header 与全局 Header，或鉴权会生成 Header 时，复制要求 Header 名称公开，以保留同名覆盖规则。以上配置仍可直接发送，并通过原生集合保留完整模板。

CurlGo 原生和 Postman 集合保留请求中的引用，不导出机密文件或主密钥；勾选导出环境也只包含普通变量。旧环境若包含保留前缀的键，导出会跳过并提示；原生导入拒绝此类普通环境键，Postman／Bruno 导入跳过并提示单独配置。直接填写的字面凭证及普通环境值仍可能出现在导出文件中。

## CLI 显式注入

CLI 不访问桌面工作区、加密文件或钥匙串。使用一个私有 JSON 文件，例如 `secrets.json`：

```json
{
  "schemaVersion": 1,
  "variables": {
    "token": "documentation-only-token",
    "password": "documentation-only-password"
  }
}
```

请求文件可独立保存或分享引用：

```json
{
  "schemaVersion": 1,
  "request": {
    "url": "{{base_url}}/health",
    "auth": {"mode": "bearer", "token": "{{secret.token}}"}
  },
  "settings": {
    "environment": "local",
    "environments": {"local": {"base_url": "http://127.0.0.1:8080"}}
  }
}
```

在 Unix 上，机密文件须为当前调用可读的普通文件，不能允许组或其他用户访问；使用 0700 私有目录和 0600 文件。Windows 文件模式不能表达完整 ACL，需由调用方限制文件权限。文件最多 1 MiB，只接受一个版本 1 JSON 文档；变量名不含前缀，值必须为字符串，未知字段、`null` 和尾随文档均会被拒绝。

```sh
curlgo run --request request.json --secrets-file secrets.json --dry-run
curlgo run --request request.json --secrets-file secrets.json
curlgo run --curl request.curl --secrets-file secrets.json
```

`--secrets-file` 只接受显式文件路径，不能使用 `-` 或直接传值。这些值只用于当前调用，不修改输入文件或环境，不从系统变量获取。`--dry-run` 读取并校验机密及请求，不发送网络请求、不写状态或响应文件；成功输出不包含 URL、凭证或请求正文。帮助不读取机密文件。

缺失引用返回 `MISSING_SECRET`，私有文件不可读、权限或格式无效返回 `INVALID_SECRETS`，退出码均为 1。错误提示不回显文件路径、原始内容或底层错误。

## 响应提取与输出

登录请求可配置 `{"variable":"secret.token","source":"json","selector":"/data/access_token"}`。桌面端在完整 2xx 响应、断言及全部提取规则通过后，将机密目标作为一个批次写入发送时的环境。需要先解锁；机密校验或保存失败时，普通目标也不更新。

混合批次先持久化机密文件，再更新普通变量并交给现有工作区异步保存。规则或机密写入失败没有部分更新，但这两个文件不构成跨文件的崩溃原子事务：进程在两次保存之间退出时，机密可能已更新而普通变量还未保存。

CLI 显式返回 `result.extractedVariables`，包括 `secret.token` 等键，不修改 `--secrets-file`。继续登录链时，用结构化序列化将 `secret.token` 的值写入下一次私有文件的 `variables.token`；普通提取值才合入下一次请求的 `settings.environments`。先检查状态、断言与业务结果再继续。

原始响应、响应头、Cookie、实际 URL 和显式提取值仍可能包含服务器返回或请求携带的凭证。桌面传输错误对机密请求使用固定提示，CLI 诊断不回显输入，但原始响应和正常执行输出没有普遍脱敏保证。应私密捕获这些输出，不将其原样写入报告。
