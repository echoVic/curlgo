# 键盘快捷键

CurlGo 的常用操作都有键盘快捷键，全部（包括「停止请求」）都可以在「设置 → 快捷键」里改成自己喜欢的组合。唯一的限制在录制新组合时：单独按 Esc 会取消录制、单独按 Backspace 会恢复该行默认值，所以不能把单独的 Esc 录成新绑定；「停止请求」的默认键就是 Esc，改动后用该行的「恢复默认」即可改回。快捷键保存在本地工作区（`settings.shortcuts`），不联网、不上传。

## 默认快捷键

| 操作 | macOS | Windows / Linux |
|---|---|---|
| 新请求 | ⌘ N | Ctrl+N |
| 收藏请求 | ⌘ S | Ctrl+S |
| 发送请求 | ⌘ ↵ | Ctrl+Enter |
| 聚焦地址栏 | ⌘ L | Ctrl+L |
| 停止请求 | Esc | Esc |
| 打开设置 | ⌘ , | Ctrl+, |

页脚、发送按钮和收藏按钮上的提示会跟随当前绑定和平台显示；地址栏获得焦点时也能用发送快捷键（不必先点空白处）。macOS 与 Windows 的中文界面分别显示 `⌘` 与 `Ctrl`，不会互相串台。

## 自定义

「设置 → 快捷键」列出全部可自定义的操作：

1. 点某一行的 **更改**，该行变成「按下新的快捷键…」输入框并自动获得焦点。
2. 按下新组合：需要包含 Ctrl/Cmd 或 Alt；单独的 Esc 与 F1–F12 也允许（Esc 用于取消录制，不能录成裸 Esc，可用 Shift+Esc）。
3. 组合被占用时会提示「该快捷键已被「某操作」使用」，不会覆盖；重新按一个空闲组合即可。
4. **Backspace** 恢复该行默认值；**Esc** 取消录制；卡片底部的 **全部恢复默认** 清除所有自定义。
5. 修改立即生效并保存，重启后保留。

录制期间菜单快捷键（含退出、撤销/复制/粘贴）会临时让位给录制输入，避免按 Ctrl+Q 直接把应用退出；结束录制后菜单恢复。录制时的输入框只用于接收组合键，不会输入文字。

## 存储格式

自定义只保存与默认值不同的覆盖项，工作区 `workspace.json` 形如：

```json
{
  "settings": {
    "shortcuts": {
      "send": "Mod+J",
      "save": "Ctrl+Shift+S"
    }
  }
}
```

组合字符串的语法：`Mod`、`Ctrl`、`Alt`、`Shift` 四个修饰键（用 `+` 连接，顺序不限）加一个按键名；`Mod` 在 macOS 上是 Command，在 Windows/Linux 上是 Ctrl。按键名支持 `A`–`Z`、`0`–`9`、`Enter`、`Escape`、`Tab`、`Space`、`Backspace`、`Delete`、`Insert`、`Home`、`End`、`PageUp`、`PageDown`、方向键、`F1`–`F12` 以及 `Comma`、`Period`、`Slash`、`Semicolon`、`Minus`、`Equal`、`Quote`、`Backslash`、`BracketLeft`、`BracketRight`。

手改配置文件也安全：未知操作、无法解析的组合、与其它操作冲突的组合会在运行时被忽略并回退到默认值，不会让应用启动失败；这类残留覆盖仍可在设置页逐行「恢复默认」。

## 说明

- 中文输入法处于中文模式时，部分 Ctrl 组合会先被系统输入法处理（例如 Ctrl+J）；切换为英文输入后再使用快捷键。这是 Windows/macOS 输入法的行为，不是 CurlGo 拦截。
- `Esc` 在记录新组合时固定用于取消；如需把「停止请求」改回 Esc，用该行的「恢复默认」。
- 菜单里的「设置…」加速键会跟随「打开设置」的自定义组合更新。
