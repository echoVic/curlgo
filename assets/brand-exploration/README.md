# CurlGo identity explorations

Three original concepts. The user selected **A — 双向回路** on 2026-11-04; production assets live in `../brand/` and `../icon.svg`.

| Concept | Idea | Palette |
| --- | --- | --- |
| A — 双向回路 | C-shaped request path with a returning response arrow | Petrol, mint, ivory |
| B — 卷曲 C | Bold C with a folded terminal | Violet, porcelain |
| C — 快速交换 | Two opposing arrows | Charcoal, coral, cream |

`comparison.png` is the review board. Each concept directory contains a standalone mark, monochrome mark, horizontal wordmark, and transparent 1024px desktop icon, with smaller PNG exports.

Marks are SVG paths. Wordmarks retain editable text using Helvetica Neue / Arial; outline the final selected typography before distributing a portable production wordmark. The desktop icons include padding around an 864px rounded tile on a 1024px transparent canvas.

Regenerate using Python 3 and `rsvg-convert`:

```sh
python3 assets/brand-exploration/create-previews.py
```

These are archived concept assets. Regenerating them does not replace the selected production identity.
